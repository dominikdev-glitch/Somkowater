# Somko Water

Responsive single-page Somko Water landing page.

## Deploy on Netlify
- Build command: leave blank
- Publish directory: `.`

## Required media
The landing page references `somko-hero.mp4` for its scroll-scrubbed product animation. Add the original video file to the repository root with that exact filename to enable the centerpiece animation. The HTML, CSS, and JavaScript are uploaded; the video asset was not available in the files accessible for this upload.
